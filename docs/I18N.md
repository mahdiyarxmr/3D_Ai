# Internationalization (i18n)

Localization is a core architecture requirement, not a later patch.

Initial locales:
- en
- ja
- fa

Fallback chain:
requested locale -> English -> key name

Every translation key must be stable and namespaced.

Example:
settings.language.title
settings.language.english
settings.language.japanese
settings.language.persian

Do not construct UI sentences by concatenating translated fragments when grammatical ordering may differ. Prefer complete localized strings with interpolation variables.
